# Triage 标签

技能使用五个规范角色。本文件把这些角色映射到本仓库 tracker 上的实际标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签           | 含义                         |
| -------------------------- | -------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此工单         |
| `needs-info`               | `needs-info`         | 等待报告者补充信息           |
| `ready-for-agent`          | `ready-for-agent`    | 已写清，可供 AFK agent 开工  |
| `ready-for-human`          | `ready-for-human`    | 需要人类来实现               |
| `wontfix`                  | `wontfix`            | 不会处理                     |

技能提到某个角色时（例如「打上 AFK-ready 标签」），使用上表右侧字符串。

若你方 tracker 已有另一套名字，只改右列。
